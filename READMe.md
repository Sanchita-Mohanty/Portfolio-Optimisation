# 🌟 Portfolio Optimization 📈

## 🚀 **Summary**
**Portfolio Optimization** is an exciting project that focuses on optimizing investment portfolios to achieve maximum returns while minimizing risk. We utilize advanced data analysis techniques and financial models like **Mean-Variance Optimization** to create the **optimal portfolio** based on historical data and market trends. 

This project was **forked** from a group project and is now being presented as an individual project. Feel free to explore and contribute!

---

## 💡 **Key Features**

- **📊 Mean-Variance Optimization**: Optimize portfolio allocation by minimizing risk for a given level of expected return.
- **📉 Efficient Frontier Visualization**: See the trade-off between risk and return for various portfolio allocations.
- **📅 Historical Data Analysis**: Analyze historical stock data to assess asset performance and volatility.
- **🔍 Risk Metrics**: Calculate important risk metrics such as **Standard Deviation**, **Sharpe Ratio**, and **Value at Risk (VaR)**.
- **📈 Portfolio Performance**: Evaluate the portfolio's performance over time and optimize it under different market conditions.

## 🚀 **Getting Started**

### **Prerequisites** 

Before you begin, ensure you have the following installed on your system:
- **Python 3.x**
- **pip** (for managing Python packages)
- **Streamlit** (for the interactive dashboard)
- **yfinance** (for fetching stock data)

---

### **Installation**

1. **Clone the Repository**:
    ```bash
    git clone https://github.com/YOUR_USERNAME/Portfolio-Optimization.git
    cd Portfolio-Optimization
    ```

2. **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

3. **Run the Application**:
    To start the app, run the following command:
    ```bash
    streamlit run app.py
    ```

4. **Access the App**:
    Open your browser and go to:
    ```bash
    http://localhost:8501
    ```

    **Live Demo**: You can also try the live demo of the app here:
    - [**Portfolio Optimization - Live Demo**](https://portfolio-optimisation-an9gcnqzkrj5szhm9eabge.streamlit.app/)
